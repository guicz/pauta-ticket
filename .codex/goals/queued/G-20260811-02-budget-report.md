# Goal G-20260811-02 — Produce the current budget report

## Status and route

- Status: `queued`
- Owner workspace: reporting owner task to be selected after current account
  evidence is available.
- Pauta scope: priority, dependency, status, and return point only.

## Useful outcome

Produce one budget report using current confirmed financial evidence without
confusing balance, planned budget, spend, invoice, contribution, or platform
limits.

## Success criteria

1. Exact clients/accounts and reporting cutoff are confirmed.
2. Current sources and collection times are recorded.
3. Missing balances are `not_confirmed`, never zero.
4. Final artifact and audience are verified in the owner task.

## First task

- Action: after the account review, confirm exact scope, cutoff, audience, and
  delivery deadline.
- Done condition: every row has an identity, period, source, and financial
  definition.
- Timebox: 5 minutes.
